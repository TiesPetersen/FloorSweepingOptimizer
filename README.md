# FloorSweepingOptimizer
A C++ optimizer that generates efficient floor sweeping routes on grid maps with obstacles using simulated annealing.

## Project Overview

The FloorSweepingOptimizer consists of 3 parts:

1. **MapGenerator** (`/src/MapGenerator`)
    
    In order to run the optimizer we will need to have a map with obstacles. This can be generated by the `MapGenerator`. It uses the Processing environment to allow for an interactive map editor. Once the map is designed, it will export a txt file (`map.txt`) containing the tiles and obstacles and another txt file (`adjacency_list.txt`) containing the adjacency list of the graph with weights.
    
    Go to #MapGenerator for more details.

2. **PathOptimizer** (`/src/PathOptimizer`)

    The `PathOptimizer` will run the simulated annealing algorithm on the adjacency list txt file (`adjacency_list.txt`). The optimizer is generic and can be run on any adjacency list, even ones that aren't generated by a grid structure (see #Note). The optimizer is coded in C++ for performance reasons. Parameters can be tuned. Once done, it will output the path as a txt file (`path.txt`).

    Go to #PathOptimizer for more details.

3. **PathVisualizer** (`/src/PathVisualizer`)

    Run the `PathVisualizer` to view the optimized path on top of the map. This also uses the Processing environment for easy visualization and consistency across the project.

    Go to #PathVisualizer for more details.

## Note

This project can easily be extended to work on generic graphs instead of grid maps, feel free to use this as inspiration to work on top of.
The optimizer is generic and works for any adjacency list (as long as the `map.txt` file is in the correct format), so feel free to use this optimizer in your own projects (with appropriate referencing).
